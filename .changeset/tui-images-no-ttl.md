TUI 支持私有镜像，新建向导可选私有镜像和不限时 TTL。

- 看板按 `i` 打开私有镜像列表（名称、UUID、状态、大小、创建时间），每次进入都重新读取，`r` 刷新；会翻完所有分页。
- 实例详情页按 `i` 输入名称，把实例保存为私有镜像。删除、重命名、共享镜像开放 API 没有提供，列表页注明需到网页控制台操作。
- 新建向导的镜像步骤列出已保存完成的私有镜像（排在公共镜像前），未完成的不列出并提示数量。私有镜像没有 CUDA 信息，按 CUDA ≥ 11.8 创建，与 `autodl create --image <私有镜像>` 一致，确认页注明。
- 向导各步列表超出终端高度时随光标滚动并显示位置，不再在矮终端里被挤出画面；修复镜像列表重复 key 的 React 警告。
- 镜像列表、GPU 库存、文件管理的本地/远程两栏、传输队列改用与实例看板相同的带标题边框；库存列表超出终端高度时随光标滚动，不再挤掉底部说明和状态栏。
- 文件管理：选中项保持在窗口中间（原来总贴在窗口最上或最下）；刷新目录和传输完成后的自动刷新不再把光标拉回第一项，返回父目录时停在刚离开的文件夹；新增 PgUp/PgDn 翻页、Home/End 跳到首尾；按键提示按终端宽度自动换行，不再截断。传输队列、向导等所有滚动列表共用同一套居中窗口计算。
- 新建向导的 TTL 增加「不限时」：不设关机定时器、不记录 TTL 台账，确认页给出持续计费警告，等价命令不带 `--ttl`。默认仍是 2h。
- SDK 新增 `listAllPrivateImages`，自动翻页。
