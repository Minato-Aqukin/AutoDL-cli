修复代码审查发现的 CLI 与 TUI 行为问题：

- TUI 重新登录继续遵守 `--token`、`AUTODL_TOKEN`、配置文件的优先级；覆盖 Token 失效时不再静默切换账号。
- CLI 参数错误统一使用退出码 2；JSON 模式下的解析错误与 `tui --json` 都返回结构化错误。
- 运行实例的单价未齐时不再给出确定续航或声称不产生费用。
- 库存查询的认证失败会传播到会话失效处理器，普通单地区错误仍允许返回其他地区的库存。
- 看板按终端宽度计算面板堆叠高度及提示换行，在 80×24 等矮屏保留实例列表和按键提示。
